# LIFE / RECEIPTS

> **Every moment leaves a receipt.**  
> A production-grade digital life story application that transforms multi-modal personal data footprints into an interactive, editorial museum experience.

---

## 🌟 Key Highlights & Features

- **Multi-Modal Data Ingestion Engine**:
  - 🟣 **Spotify Web Audio History**: Play counts, artists, listening time, and genre inference.
  - 🔵 **Indian Banking & UPI Transactions**: Merchant categorizations, debit/credit flows, formatted in INR (₹).
  - 🟠 **Daily Household Expenses**: Daily household grocery, transportation, dining, and utility logs.
- **Interactive 3D Typography & Motion**:
  - **`DepthText`**: 3D extruded typography with cursor tilt and orbital velocity.
  - **`EchoText`**: Trailing ghost motion typography with pointer physics.
  - **`DriftWall`**: 3D isometric memory gallery with parallax tracking.
  - **`PixelSwap`**: Web Animations API coordinate matrix pixel-burst flip cards.
  - **`GlassIcons`**: 3D frosted-glass quick-lens filter toolbar.
  - **`LogoLoop`**: Continuous marquee of ingestion sources and protocols.
- **Heuristic Connection Engine**:
  - Deterministic discovery of temporal proximity, shared date intervals, category correlation, and activity clusters.
- **Interactive Recharts Analytics**:
  - Spline Area vs. Stacked Bar toggles with neon linear gradients and custom glassmorphic tooltips.
- **Strict Client-Side Privacy**:
  - Zero external servers. All card numbers masked (`•••• 1234`) and processed strictly inside the browser.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Language**: TypeScript
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) & [GSAP](https://gsap.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **CSV Engine**: [PapaParse](https://www.papaparse.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

### 3. Build for Production
