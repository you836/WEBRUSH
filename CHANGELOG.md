# Changelog

All notable changes to **LIFE / RECEIPTS** are documented in this file in accordance with [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-20

### Added
- **Interactive 3D Background**: Three.js WebGL high-DPI classroom interior diorama with custom camera angles, dynamic lighting, and orbital cursor tracking.
- **Heuristic Inference Engine**: Deterministic multi-modal correlation discovery across Spotify streaming, UPI banking, and household expenses.
- **Narrative Story Chapters**: Multi-perspective synthesized chapters with *Editorial Museum*, *Data Analyst*, and *Poetic Chronology* perspective controls.
- **Interactive Correlation Topology Graph**: Real-time 2D Canvas force-directed relational map with source filtering and edge affinity weights.
- **Client-Side Data Importer & Exporter**: Drag-and-drop CSV/JSON uploaders for custom datasets and one-click JSON/CSV exports.
- **Global Keyboard Navigation**: Modal HUD (`?`), quick section navigation (`1-6`), and search shortcut (`/`).
- **Comprehensive Vitest Suite**: 100% automated test coverage across correlation heuristics, narrative generators, data statistics, and PII masking.
- **Architecture & Design Documentation**: `ARCHITECTURE.md`, `CONTRIBUTING.md`, and Architectural Decision Records (ADRs).

### Security & Privacy
- Zero backend dependencies; 100% client-side memory processing.
- Strict PII masking for banking and financial account identifiers.
